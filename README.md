## Краткая формализация, принцип и формула

### 1. Формализация (определения)

Система состоит из трёх взаимодействующих компонентов:

**V-дерево** — иерархическая структура, каждый узел которой имеет объём `V`. Объём узла вычисляется как сумма объёмов его потомков плюс единица:

```
V(node) = 1 + Σ V(children)
```

**C-дерево** — параллельная иерархия, каждый узел которой имеет содержание `C`. Содержание узла жёстко связано с объёмом соответствующего узла в V-дереве через закон обратного отношения.

**Буфер неопределённости** — хранилище сложных задач, которые не могут быть решены из‑за недостатка данных; их решение становится возможным по мере роста деревьев.

---

### 2. Принцип (закон обратного отношения и каскадность)

**Центральный закон:**

```
C = k / V   (при k = 1: C = 1/V)
```

Это означает, что с увеличением объёма содержание убывает, и наоборот.

**Каскадное распространение**

Любое изменение объёма одного узла в V-дереве:

1. немедленно пересчитывает объёмы всех его предков (по формуле суммы потомков);
2. через связь `C = 1/V` обновляет содержание соответствующего узла в C-дереве;
3. вызывает пересчёт содержания всех предков в C-дереве;
4. перестраивает оба дерева (ротациями) для сохранения инварианта: родитель имеет больший или равный объём (содержание) по сравнению с потомком.

**Буфер неопределённости** работает по принципу накопления: при каждом пересчёте деревьев система проверяет, достаточно ли данных для решения задач из буфера. Если данных стало достаточно — задача решается, её результат добавляется в деревья, что увеличивает их размер и уменьшает общую неопределённость.

---

### 3. Формулы (базовые соотношения)

| Величина | Формула | Описание |
|----------|---------|----------|
| Объём узла | `V(node) = 1 + V(left) + V(right)` | Рекурсивное определение (для бинарного дерева) |
| Содержание узла | `C(node) = 1 / V(node)` | Закон обратного отношения (коэффициент может быть параметром) |
| Изменение объёма | `V(node) ← V(node) + ΔV` | Вызывает каскадный пересчёт предков |
| Пересчёт предков | `V(parent) = 1 + Σ V(children)` | Выполняется снизу вверх до корня |
| Обновление содержания | `C(parent) = 1 / V(parent)` | Синхронизируется с V-деревом |
| Мера неопределённости | `U = 1 / N` | |

## Итоговое ядро системы

Итоговое ядро системы можно выразить одной парой рекурсивных соотношений:

```
V(node) = 1 + V(left) + V(right)
C(node) = 1 / V(node)
```

с условием, что любое изменение `V(node)` немедленно пересчитывает все `V` и `C` предков, а также перестраивает иерархию, обеспечивая глобальный инвариант:

- `V(parent) ≥ V(child)`
- `C(parent) ≤ C(child)`
